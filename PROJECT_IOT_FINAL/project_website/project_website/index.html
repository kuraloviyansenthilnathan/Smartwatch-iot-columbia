Smart Alarm Clock

Our project is on building and programming an Internet of Things alarm clock. A smart alarm clock typically offers a myriad of features such as:

• Changing or adjusting the Alarm time automatically on the basis of Weather conditions, Traffic Routes and also on the basis of whether the day is a weekend or a weekday.

• In A Smart Alarm Clock, A pressure sensor is placed under the mattress and pillows that a person is using. This Sensor can measure your sleep and will also be able to determine whether the person is getting enough sleep or not. It can also recognize your sleep patterns and recommend any change if required.

• Another feature to be implemented would be for the person required to walk to another area of the apartment/house to find a Randomly generated code on the OLED display screen so that they can type that code in their phone to stop the alarm. This forces the person to wake up from their bed and walk around the apartment.

• It also allows you to set an alarm though multiple methods in the computer, text to speech synthesis and also provides a feature to send a notification to your roommates if you have not woken up to the alarm for a period of time.

Motivation

Motivation

Alarm clocks have been around for a long time because they solve a real problem: making sure we get up on time!

They are vital to our living schedule and many of us would have great difficulties getting to class each day if we didn't have one. Even though most people use their phones as their primary alarm clocks, we believe there is still room for a smart alarm.

The problem is that, in addition to the issue of space, you need something with a lot of features and that will work well in comparison to a conventional alarm.

Smart alarm clocks are devices that do not use the boring standard methods of waking you up, and they are designed not to violently interrupt your sleeping cycle and put you in a groggy mood that can potentially last all day long. It can not only provide innovative ways for you to wake up, but also help improve your sleep schedule.

A smart alarm clock typically offers a myriad of features which a conventional alarm/phone cannot.

The global smart alarm clock market is expected to grow at a CAGR of around 8.5% during the forecast period, from 2021 to 2030. The market is driven by factors such as increasing demand for smart alarm clocks in the travel industry and rising awareness about the benefits of using these devices.

System

Architecture

The Smart Alarm system will utilize:

3 different ESP 8266 microchips and an Arduino UNO board to interface with various sensors and modules.

Pressure Sensor/ Load cell: This sensor will fetch data while kept under the bed/pillow to detect sleep activity. This helps in tracking sleep time/schedule and recognizing sleep patterns.

OLED module: This would display the randomly generated code. User then enters the code on the application to disable/end the alarm.

AWS Cloud Server: A web application will be built to interface with the alarm system and its features related to sleep tracking, weather, traffic conditions etc.

In addition, E-mail notifications would be sent to acquaintances if required by the user.

Temperature and Humidity Sensor: This would fetch temperature and humidity values of the room and provide feedback in correlation with its impact on the user's sleep activity.

Prototype

We can set the alarm manually by using the buttons on the OLED display or we can set it using the computer.
The alarm has a red LED bulb for visual lighting effect and 2 Piezos for audio effect. The alarm system is built using the Huzzah ESP8266 microchip.

The Temeprature and Humidity sensor is also connected to another Huzzah ESP8266 microchip and it takes the readings of both the temperature and humidity of the room every 10 minutes to keep track of any slight changes. High humidity will increase the wakefulness of the user and reduce the amount of time the user spends in both slow-wave NREM and REM sleep. Since both of these stages are crucial for the user's overall health, sleepers may experience additional issues related to bodily recovery and memory consolidation.

The server generates a random code which is fetched by the code generator system through AWS server API.

Results

We have completed all parts of our features list.
The Alarm System Clock time, alarm time and date could be set manually by the user. Once the Alarm starts ringing, the user needs to send the Randomly generated code through the app to stop the alarm.

All the systems interface and transfer data through the AWS EC2 Server.

Incase the alarm is not deactivated by the user for more than 10 minutes, an E-mail is sent automatically to the recipients chosen by the user to notify them.

Load cells/Pressure sensors are placed under the pillow and mattress to detect whether the user is asleep and keep track of his sleep activity on a day to day basis.

We have also incorporated IP API, Flask RESTful API, TomTom API in order to adjust the alarm time automatically on the basis of weather conditions, traffic routes and whether it is a weekend or a weekday.

Our web portal also shows us our sleep activity, temperature and humidity on a day to day basis to help us understand and keep track of our sleep schedule.
